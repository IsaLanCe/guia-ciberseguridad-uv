    • Nomenclatura y símbolos

    Para poder comprender cada una de las secciones, específicamente de las actividades, se anexa el significado de cada uno de los siguientes iconos:

    Ícono Teórico

    Sección donde el estudiante obtendrá la teoría del tema correspondiente.

    Ícono de Nota

    Apartado de apoyo para el estudiante en forma de párrafos informativos los cuales complementaran sus conocimientos.

    Ícono de Práctica

    Actividad práctica en la cual el estudiante debe realizar un escenario practico, el cual ayudar a articular el conocimiento previamente obtenido con un escenario practico.

    Ícono de Descarga

    Elemento el cual indica que se puede obtener un recurso adicional necesario para poder ejecutar la actividad práctica.

    Ícono de Evaluación

    Conjunto de evaluaciones para el estudiante, las cuales confirman la realización de la actividad y los elementos que se deben cubrir.

    Ícono de Diagrama

    Se usará este ícono para identificar algún esquema o diagrama de apoyo para el estudiante.
